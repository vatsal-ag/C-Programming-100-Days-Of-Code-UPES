# 100 Days of Code: C Programming

This repository serves as a complete log of my progress through a 100 Days of Code challenge focused entirely on the C programming language.

## Overview
The objective of this challenge was to develop a deep understanding of C by committing to writing code and solving programmatic challenges every day for 100 consecutive days. This repository contains all of the code and solutions developed over that period.

## Structure
The codebase is organized into primary question groups (e.g., Q1 - Q10) and then further subdivided into daily folders. This structure reflects the steady progression of concepts and problems tackled throughout the challenge.

## Motivation
C is a foundational programming language that provides deep insights into memory management, system-level programming, and core computing principles. This repository demonstrates a sustained commitment to mastering these fundamental engineering concepts.
